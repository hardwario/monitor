# 0004 — Integrated MCP server

- **Status:** [features/0013](features/0013-m6-mcp-core-cli.md) (core, tools, CLI) implemented;
  [features/0014](features/0014-m6-mcp-gui.md) (GUI) implemented 2026-11-04 (J-Link and Bluetooth tabs; the manual
  checks C2 on Linux, Windows and macOS are open). ADR-0094–ADR-0108, ADR-0240–ADR-0244. The feature plans and ADRs
  are authoritative where this overview differs (port 47800, token file, tool names, consent categories).

## Transports

- **GUI:** MCP over Streamable HTTP on `127.0.0.1` (port 47800 by default, configurable), bearer token in an
  owner-only file (shared with `hwio mcp --token-file`), shown in Settings → AI assistants (MCP) with client
  snippets (Claude Code HTTP, `.mcp.json`, Claude Desktop over stdio). Disabled by default. The devices are the open
  tabs: the AI works on the **same live session** the user sees; `connect` opens an "AI" tab (or connects the user's
  tab of that probe) after consent.
- **CLI:** `<cli> mcp` (executable name: open-questions #5) serves MCP over stdio for AI tools and CI without the GUI.
- Both share `libs/mcp` (protocol, JSON schema of tools, tool registry) and call the same
  `libs/device` API.

## Tools (initial proposal, mirroring rttt)

| Tool | Destructive | Description |
|---|---|---|
| `list_probes`, `session_status` | no | discovery and state |
| `connect`, `disconnect`, `reconnect` | no | session control |
| `send_command` | maybe | send shell command, return output until prompt/timeout |
| `read_log` | no | read log lines (since cursor, filter, limit) |
| `wait_for_state` / `wait_for_log` | no | wait until regex appears or timeout |
| `reset`, `halt`, `go` | yes | target control |
| `flash` | yes | flash file or catalog ID |
| `read_memory`, `memory_zones`, `read_registers` | no | debug inspection |
| `write_memory`, `write_flash`, `erase` | yes | — |

## Security

- Localhost only; token required; Origin header validation (DNS-rebinding protection).
- Destructive tools require user confirmation in the GUI (per consent category: Ask / Always allow, remembered per
  client until it disconnects; an always-on-top prompt window, ADR-0101, ADR-0108, ADR-0241), and are visibly
  logged in the UI (console markers "— AI (Claude Code): flash app.hex —", the activity list, the rail indicator;
  ADR-0105).
- All inputs validated and bounded (sizes, addresses within memory zones, timeouts).
