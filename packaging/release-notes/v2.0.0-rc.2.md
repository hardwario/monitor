The first release candidate of **HARDWARIO Monitor 2**, a complete rewrite of HARDWARIO Monitor: the console, log and flashing tool for HARDWARIO CHESTER, as a desktop app for Windows, macOS and Linux and as the command-line tool `hwio`.

This is a pre-release for testing. Please report problems in [Issues](https://github.com/hardwario/monitor/issues); `hwio diag report` (or **Help › Create diagnostic report…** in the app) creates a report you can attach.

## What is in HARDWARIO Monitor 2

**Console**
- The device's shell and its log side by side; search and filters (text, regular expression, level), pause, copy, saved views.
- Suggestions from the device's own command list and from your history; batch files of commands.
- Up to eight devices in tabs; each reconnects by itself after a reset or a power cut.
- Every session is written to a console file.

**Flashing**
- Application firmware from a `.hex` file or a firmware catalog ID; the recommended HARDWARIO LTE firmware is downloaded and verified for you.
- Erase, reset and recover of the application and LTE MCUs.
- The UICR is written only when you allow it; the Product Information Block (serial number, claim token) is never overwritten by a flash.

**Bluetooth LE**
- The CHESTER shell over Bluetooth, without a J-Link: in the app (device picker, pairing) and with `hwio ble`.

**Command line `hwio`**
- The same features in a terminal and in scripts, `--json` output, low-level target commands.
- Keeps the commands of py-hardwario's `hardwario`, so existing scripts keep working ([migration guide](https://github.com/hardwario/monitor/blob/main/docs/en/cli-migration.md)).
- `hwio mcp`: an MCP server for AI assistants (Claude Code, Claude Desktop, Cursor, VS Code); flashing and erasing only when you allow them.

**Also**
- Every error explains what happened, why, and what to do.
- English and Czech user interface; light and dark theme.
- `hwio doctor` checks the installation; the diagnostic report removes your user name and secrets.
- A notice when a newer version is out (checked on GitHub once a day, nothing about you is sent); no telemetry.

Every package holds the app and `hwio`. Install **SEGGER J-Link Software 8.00 or newer** separately, and **Nordic nRF Util** for the LTE modem firmware; neither is included. Then run `hwio doctor` or start the app: [Installing](https://github.com/hardwario/monitor/blob/main/docs/en/install.md) · [Getting started](https://github.com/hardwario/monitor/blob/main/docs/en/getting-started.md).

- **Windows:** SmartScreen may not know the new installer yet; choose **More info → Run anyway**.
- **Linux AppImage:** install the J-Link udev rule yourself (see Installing).
- The `symbols-*.zip` files are debug symbols for crash analysis; you do not need them.

**Verify a download:** `sha256sum -c SHA256SUMS --ignore-missing`, or `gh attestation verify <file> --repo hardwario/monitor` (build provenance from GitHub Actions).

## Known limitations of this release candidate

- Tested on real CHESTER hardware on Linux; the manual checks on Windows and macOS are still running.
- `hwio chester app halt` halts the CPU only while the command runs; it is running again after the command exits.
- Bluetooth: with many devices nearby the app may preselect a different one than expected.
- The user interface is in English and Czech only; the documentation is also in German, Slovak and Polish.
- MCP is available in `hwio`; the MCP server inside the desktop app follows after 2.0.0.
- The app does not update itself; install a newer version over the old one, settings are kept.
- There is no 2.0.0-rc.1 release: that tag stopped in the release checks before any package was built.
